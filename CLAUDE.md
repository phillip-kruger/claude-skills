# Quarkus Development Skills

When asked to do a full build, complete build, rebuild, or "build everything", use the `/full-quarkus-build` skill.

When asked to decompile a class, view a class from a dependency, or understand a library's internals, use the `/decompile` skill.

When asked to find which JAR contains a class, search for a class on the classpath, or resolve import/classpath issues, use the `/classpath-search` skill.
